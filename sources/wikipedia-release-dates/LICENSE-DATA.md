# English Wikipedia release dates (hints)

- **What we take:** for well-known games whose Wikidata release date is only a month or a year, the **day-precision release dates** written in the "released" line of the English Wikipedia article's infobox, with the short platform label written before each date (for example "PS5, Windows") and a note such as "early access". Redirects are never followed: a title that only redirects to another article has no dates of its own here. Nothing else is copied — no sentences, no references, no other text.
- **Why:** to find dates that are already public but not yet on Wikidata. Each one becomes a row in `reports/dates-to-update.csv` for a person to check against a real source (the publisher's announcement, a store page, press) and then add to Wikidata **with that source**. A Wikipedia date is never used as a source itself, and DropSlate never shows these dates.
- **Licence:** Wikipedia's text is [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Release dates are facts, but to be safe this file is shared under **CC BY-SA 4.0**, with credit to the English Wikipedia contributors; each entry names the article (`title`) and the revision time (`revision`) it came from.
- **Script:** `scripts/dates_to_update.py` · **Output:** `sources/wikipedia-release-dates/dates.json` (`{"format": 1, "as_of", "games": {Wikidata ID: {"title", "revision", "dates": [{"date", "platforms", "note"}]}}}`)
