# Security

This repository holds open game data and the small scripts that fetch it. It has no website, no accounts and no secrets.

## Reporting a problem

If you find a security problem (for example in a workflow or script), please report it privately: **Security → Report a vulnerability** on this repository. Please don't open a public issue for it.

I'm one person doing this in my spare time, so I aim to reply within a week and to fix confirmed problems as soon as I can.

## Wrong data is not a security problem

If a game's facts look wrong, the best fix is on [Wikidata](https://www.wikidata.org), ideally with a reference. For problems with how the data is matched here, open a normal issue.
